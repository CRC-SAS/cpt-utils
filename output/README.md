# output

Archivos CSV en formato CPT (IRI Climate Predictability Tool) generados por `netcdf_to_cpt.py`
(ERA5) o `ecmwf_to_cpt.py` (pronóstico estacional ECMWF).

El nombre de cada archivo refleja la variable, el mes y el rango de años del contenido. Ejemplo: `HG500_jun_1961_2026.csv` contiene altura geopotencial a 500 mb para el mes de junio entre 1961 y 2026.

# input/hourly

Archivos NetCDF con datos sub-diarios (cada 6 horas: 0, 6, 12 y 18 UTC) de entrada.

Estos archivos se promedian a un único valor mensual antes de concatenarse con los datos mensuales. Ejemplo: `HG500_jun_2026.nc` contiene altura geopotencial a 500 mb con resolución de 6 horas para junio 2026.
